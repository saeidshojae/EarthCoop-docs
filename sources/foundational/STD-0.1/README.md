# STD 0.1 base-source provenance

این پوشه متن مبنای کامل **استانداردهای فنی EarthCoop — STD 0.1** را برای تلفیق قطعی STD 0.2 نگهداری می‌کند.

## منبع ورود

متن از فایل پروژه‌ای کاربر با عنوان `استانداردهای فنی EarthCoop.docx` / نسخه متنی متناظر آن استخراج شده است؛ همان متنی که STD 0.1 را از `STD-001` تا `STD-078` در بر دارد. متن به پنج فایل صرفاً برای نگهداری و پردازش پایدار تقسیم شده و ترتیب فایل‌ها بخشی از قرارداد build است.

SHA-256 متن استخراج‌شده یکپارچه، پیش از تقسیم و نرمال‌سازی Markdown:

`d7898ff1a41534f987f16f77e6c6b4e7be8e36124616882ddab506a69e952173`

> این هش برای ردیابی منبع استخراج‌شده ثبت شده است و انتظار نمی‌رود با الحاق بایت‌به‌بایت فایل‌های این پوشه برابر باشد؛ در انتقال به Markdown فاصله‌های انتهای خط و قالب‌بندی غیرمعنایی نرمال شده‌اند. قرارداد CI به‌جای ادعای برابری بایتی، توالی کامل و یکتای ۷۸ شناسه ماده و قابلیت تلفیق با اصلاحیه ثبت‌شده را کنترل می‌کند.

## قاعده نگهداری

این فایل‌ها «منبع مبنا» هستند، نه نسخه عمومی جدید. اصلاح STD 0.1 در این پوشه برای همسان‌سازی ظاهری ممنوع است. تغییر حقوقی باید از مسیر اصلاحیه نسخه‌دار انجام شود و builder نسخه جدید را از base + amendment تولید کند.

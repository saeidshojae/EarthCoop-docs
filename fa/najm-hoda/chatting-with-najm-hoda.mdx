ویجت چت NajmHoda در گوشه هر صفحه EarthCoop قرار دارد. روی ویجت کلیک کنید، سوال خود را بپرسید و در ثانیه‌ها پاسخ ساختارمند دریافت کنید.

## باز کردن ویجت

آیکون چت در پایین‌سمت‌راست صفحه بعد از ورود قابل مشاهده است. کلیک کنید.

## پرسیدن سوال

سوال خود را به زبان طبیعی تایپ کنید و **Send** را بزنید. NajmHoda خودکار:

1. کلمات کلیدی را استخراج می‌کند.
2. KB، بلوگ پست و FAQ را جستجو می‌کند.
3. به Steward ارسال می‌کند.
4. پاسخ ساختارمند برمی‌گرداند.

<Tip>
  سوالات خاص جواب بهتری می‌دهند.
</Tip>

## بازخورد

بعد از هر پاسخ، پل‌داون یا پل‌اپ بزنید و یادداشت اضافه کنید.

## ارجاع به پشتیبانی انسانی

وقتی سوال به دسترسی داده فردی نیاز دارد یا NajmHoda در KB پاسخ اطمینان‌بخش پیدا نکرده، تیکت باز کنید.

## دسترسی API

### ارسال پیام

```bash
POST /api/najm-hoda/chat
Authorization: Bearer {your-token}
Content-Type: application/json
```

```json
{
  "message": "چگونه گروه تعاونی بسازم؟",
  "agent": "steward"
}
```

| فیلد | نوع | الزامی |
| --- | --- | --- |
| `message` | string | بله (تا ۲،۰۰۰ کاراکتر) |
| `agent` | string | خیر |
| `conversation_id` | int | خیر |
| `context` | object | خیر |

### بازخورد

```bash
POST /api/najm-hoda/feedback
```

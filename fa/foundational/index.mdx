# مجموعه قوانین بنیادین EarthCoop

این بخش، درگاه رسمی دسترسی عمومی به اسناد بنیادین EarthCoop است. اسناد با شناسه پایدار، شماره نسخه، وضعیت اعتبار و سابقه تغییرات منتشر می‌شوند.

<Note>
زبان مبنای نسخه‌های کنونی فارسی است. اسناد دارای وضعیت «پیش‌نویس» برای بررسی و تکمیل منتشر می‌شوند و نباید با نسخه نهایی یا لازم‌الاجرا اشتباه گرفته شوند.
</Note>

## قواعد انتشار

- هر سند دارای شناسه، نسخه، تاریخ، زبان مبنا و وضعیت اعتبار است.
- تغییرات اسناد از طریق Git و Pull Request ثبت و قابل بازبینی می‌شوند.
- نسخه‌های نهایی و پیش‌نویس‌ها به‌روشنی از یکدیگر تفکیک می‌شوند.
- ترجمه‌ها تا زمان تصویب رسمی، تابع نسخه زبان مبنا هستند.
- در صورت تعارض، سلسله‌مراتب مقرر در سند مادر اعمال می‌شود.

## مشارکت در بررسی اسناد

برای پیشنهاد اصلاح، ابتدا Issue مستقلی باز کنید و شناسه سند و ماده مربوط را در عنوان ذکر کنید؛ برای نمونه:

```text
[CO-024] پیشنهاد اصلاح ماده مربوط به حق نظارت
```

پیشنهادهای اصلاح باید شامل متن فعلی، متن پیشنهادی، دلیل تغییر و آثار احتمالی حقوقی، اجرایی، مالی، فنی یا زیست‌محیطی باشند.

## ترتیب ثبت

1. ثبت متن نسخه‌های جدید و اصلاحیه‌ها در این بسته.
2. ثبت Concordance رسمی.
3. اجرای ممیزی بین‌اسنادی.
4. تولید متن کامل تلفیقی برای اسناد اصلاحیه‌ای همراه با provenance ماده‌به‌ماده.
5. بازبینی انسانی مستقل متن‌های تلفیقی.
6. فقط پس از تصمیم جداگانه درباره انتشار، به‌روزرسانی صفحات جاری و ناوبری عمومی.

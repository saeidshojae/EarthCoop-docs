ارث‌کوپ (EarthCoop) به صاحبان پروژه و سرمایه‌گذاران نمای کامل و بلادرنگ از هر ارسال، تصمیم و تراکنش را می‌دهد.

## برای صاحبان پروژه

### مشاهده وضعیت پروژه

به **NajmBahar ← Projects ← My Projects** بروید. صفحه جزئیات شامل:

- بج وضعیت فعلی
- تاریخ‌های کلیدی: ارسال، بررسی، تأیید یا رد
- دلیل رد در صورت ردشدن
- تاریخچه کامل بررسی
- آمار سرمایه‌گذاری‌ها

### خط زمانی وضعیت

صفحه جزئیات خط زمانی بصری از هر وضعیتی که پروژه پشت سر گذاشته را نمایش می‌دهد.

### تاریخچه بررسی

هر اقدام ادمین ثبت می‌شود.

| فیلد | توضیح |
| --- | --- |
| **بررسی‌کننده** | ادمین مسئول |
| **عملیات** | چه کاری انجام شد |
| **توضیح** | یادداشت بررسی‌کننده |
| **تاریخ** | زمان دقیق عملیات |

<Info>
  یادداشت‌های درخواست بازنگری در تاریخچه حفظ می‌شوند.
</Info>

### آمار سرمایه‌گذاری برای پروژه‌های تأییدشده

| آماره | توضیح |
| --- | --- |
| **جمع سرمایه‌گذاری** | جمع همه سرمایه‌گذاری‌های فعال و تکمیل‌شده |
| **پیشرفت** | درصد هدف سرمایه |
| **تعداد سرمایه‌گذاران** | کل تعداد منحصر‌به‌فرد |
| **کل بازده مورد انتظار** | اصل \+ سود |

## برای سرمایه‌گذاران

### مشاهده سرمایه‌گذاری‌های فعال

به **NajmBahar ← Investments ← My Investments** بروید. لیست شامل:

- **نام پروژه**
- **مبلغ سرمایه‌گذاری** بر حسب GOL
- **بازده مورد انتظار**
- **وضعیت فعلی**
- **تاریخ سررسید**

### خط زمانی وضعیت

هر مرحله (`pending` ← `paid` ← `active` ← `completed`) با تاریخ دقیق نمایش داده می‌شود.

### نمایش بازده مورد انتظار

```text
Expected Return = Amount + (Amount × Profit Percentage / 100)
```

## اعلان‌ها

### برای صاحبان پروژه

| اعلان | زمان ارسال |
| --- | --- |
| **ProjectStatusChanged** | هر تغییر وضعیت |
| **ProjectRevisionRequested** | درخواست تغییر |
| **NewInvestmentReceived** | سرمایه‌گذاری جدید |

### برای سرمایه‌گذاران

| اعلان | زمان ارسال |
| --- | --- |
| **InvestmentStatusChanged** | هر تغییر وضعیت سرمایه‌گذاری |
| **ProjectStatusChanged** | تغییر وضعیت پروژه |

## مرجع سریع

| چه می‌خواهید ببینید | کجا |
| --- | --- |
| وضعیت پروژه | NajmBahar ← Projects ← My Projects |
| تاریخچه بررسی | صفحه جزئیات پروژه |
| وضعیت سرمایه‌گذاری | NajmBahar ← Investments ← My Investments |
| بازده مورد انتظار | صفحه جزئیات سرمایه‌گذاری |
| اعلان‌ها | آیکن زنگ در بالا |

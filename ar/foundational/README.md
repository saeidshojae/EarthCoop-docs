## الزامات هر سند

هر صفحه باید دارای Frontmatter شامل عنوان، توضیح، شناسه، نسخه و وضعیت باشد. متن اصلی باید شناسه مواد را بدون تغییر حفظ کند و نسخه پیش‌نویس را به‌روشنی از نسخه نهایی جدا سازد.

تغییرات محتوایی اسناد باید در Pull Request مستقل یا با Commitهای قابل تفکیک ثبت شوند تا بازبینی ماده‌به‌ماده ممکن باشد.

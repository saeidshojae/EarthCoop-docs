حساب ارث‌کوپ (EarthCoop) شما بنیان همه کارهایی است که در پلتفرم انجام می‌دهید. پروفایل کامل و دقیق تضمین می‌کند پلتفرم بتواند شما را با گروه‌ها، پروژه‌ها و همکاران درست تطبیق دهد — و به سایر اعضا نشان می‌دهد که شما عضوی قابل‌اعتماد و متعهد در شبکه تعاونی هستید.

## ثبت‌نام

ثبت‌نام در ارث‌کوپ یک فرآیند ساختاریافته چهاربخشی است. ابتدا اعتبارنامه ورود خود را ایجاد می‌کنید، سپس پس از تأیید ایمیل، سه مرحله پروفایل را تکمیل می‌کنید. همچنین می‌توانید با حساب Google بلافاصله شروع کنید.

<Steps>
  <Step title="اعتبارنامه ورود خود را ایجاد کنید">
    در صفحه ثبت‌نام، **آدرس ایمیل** خود را وارد کنید و یک **رمز عبور** امن (حداقل شش کاراکتر) انتخاب کنید. یا **ادامه با Google** را انتخاب کنید.

    پس از ثبت، یک **کد تأیید** به ایمیل شما ارسال می‌شود. آن را در صفحه بعدی وارد کنید تا حسابتان تأیید و مراحل بعدی باز شود.

    <Warning>
      تا تأیید ایمیل، عملکرد حساب شما محدود است. تا تأیید نشوید نمی‌توانید پروفایل خود را تکمیل کنید، به گروه‌ها بپیوندید، پروژه ارسال کنید، یا از سیستم مالی نجم‌بهار (NajmBahar) استفاده کنید.
    </Warning>
  </Step>
  <Step title="مرحله ۱ — اطلاعات شخصی">
    پس از تأیید ایمیل، جزئیات هویتی اصلی خود را وارد کنید.

    | فیلد | توضیح |
    | --- | --- |
    | **نام** | نام کوچک شما که در پروفایل و لیست اعضا نمایش داده می‌شود. |
    | **نام‌خانوادگی** | نام خانوادگی شما، قابل مشاهده توسط اعضا. |
    | **تاریخ تولد** | برای تأیید حداقل سن (۱۵ سال). |
    | **جنسیت** | برای گزارش تنوع جامعه. |
    | **ملیت** | هویت ملی شما. |
    | **کد ملی** | شماره شناسایی ملی برای احراز هویت. |
    | **شماره تلفن** | تلفن همراه برای امنیت حساب و اعلان‌ها. |
    | **رمز عبور** | اگر با Google ثبت نام کرده‌اید، اینجا رمز تعیین کنید. |
  </Step>
  <Step title="مرحله ۲ — حرفه و تخصص">
    این مرحله هویت حرفه‌ای شما در پلتفرم را تعریف می‌کند و تعیین می‌کند کدام گروه‌های تخصصی به شما توصیه می‌شوند.

    | فیلد | توضیح |
    | --- | --- |
    | **حوزه شغلی** | دسته حرفه‌ای اصلی شما (مهندسی، کشاورزی، بهداشت، آموزش...). |
    | **حوزه تخصصی** | رشته تخصصی‌تر (مهندسی عمران، کشاورزی ارگانیک، برنامه‌نویسی...). |

    <Note>
      می‌توانید هر زمان حرفه و تخصص خود را از تنظیمات پروفایل به‌روزرسانی کنید.
    </Note>
  </Step>
  <Step title="مرحله ۳ — موقعیت مکانی">
    ارث‌کوپ گروه‌ها را در چندین سطح جغرافیایی سازماندهی می‌کند.

    | سطح | توضیح |
    | --- | --- |
    | **قاره** | منطقه جغرافیایی گسترده. |
    | **کشور** | کشور شما. |
    | **استان** | تقسیمات منطقه‌ای. |
    | **شهرستان** | زیرمجموعه استان. |
    | **بخش** | بخش اداری در شهرستان. |
    | **شهر یا روستا** | شهر یا روستای محل سکونت. |
    | **منطقه** | زیرمجموعه شهر یا روستا. |
    | **محله** | اجتماع محلی بلافاصله. |
    | **خیابان** | اختیاری. |
    | **کوچه** | اختیاری. |

    <Tip>
      در انتخاب محله دقیق باشید تا تطبیق گروه‌های محلی بهتر شود.
    </Tip>
  </Step>
</Steps>

## ورود با Google

اگر با Google ثبت‌نام کنید، ایمیل شما خودکار تأییدشده تلقی می‌شود. اتصال حساب Google را در **تنظیمات حساب ← امنیت ← حساب‌های متصل** مدیریت کنید.

## مرجع فیلدهای پروفایل

پس از فعال‌سازی کامل حساب، به **پروفایل ← ویرایش پروفایل** بروید.

| فیلد | توضیح |
| --- | --- |
| **نام کامل** | نام و نام‌خانوادگی. |
| **عکس پروفایل** | عکسی واضح برای تشخیص بهتر. |
| **بیو** | توصیف کوتاه از پیشینه و اهداف شما. |
| **تاریخ تولد** | فقط برای خود شما قابل مشاهده است. |
| **جنسیت** | اختیاری. |
| **ملیت** | هویت ملی. |
| **حوزه شغلی** | دسته حرفه‌ای اصلی. |
| **حوزه تخصصی** | رشته دقیق‌تر. |
| **موقعیت** | پروفایل جغرافیایی کامل. |
| **ترجیح زبان** | انتخاب انگلیسی یا فارسی. |
| **سیستم تقویم** | انتخاب میلادی یا جلالی (هجری شمسی). |

## ترجیحات زبان و تقویم

ارث‌کوپ برای یک جامعه جهانی و فرهنگی تنوع ساخته شده است. ترجیحات خود را از **تنظیمات حساب ← ترجیحات** تنظیم کنید.

- **زبان:** تغییر به فارسی یک رابط کاربری کاملاً ترجمه‌شده را فعال می‌کند.
- **تقویم:** انتخاب جلالی همه تاریخ‌های پلتفرم را به فرمت هجری شمسی تبدیل می‌کند.

<Info>
  ترجیحات زبان و تقویم شخصی هستند و بر اعضای دیگر بی تأثیرند.
</Info>

## بازنشانی رمز عبور

اگر رمز عبور خود را فراموش کردید، در صفحه ورود **رمز عبور را فراموش کرده‌اید؟** را انتخاب کنید. ایمیل ثبت‌شده خود را وارد کنید و کد بازنشانی شش رقمی دریافت کنید. کدهای بازنشانی پس از پنج دقیقه منقضی می‌شوند.

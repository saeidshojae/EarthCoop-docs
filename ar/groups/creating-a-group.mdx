در EarthCoop، گروه‌ها وقتی ثبت‌نام را تکمیل می‌کنید به‌طور خودکار ایجاد می‌شوند. به‌عنوان مدیر گروه، وظیفه شما پیکربندی و نگهداری آن فضا است.

<Info>
  اغلب اعضا به‌طور خودکار در گروه قرار داده می‌شوند. به **Groups → My Groups** بروید.
</Info>

## داشبورد گروه

برای دیدن همه گروه‌هایتان، روی **Groups** (گروه‌ها) در نوار کناری کلیک کنید. داشبورد به تفکیک نوع گروه (عمومی، حرفه‌ای، تخصصی، سنی، جنسیتی) سازماندهی شده است.

## فیلدهای گروه

| فیلد | توضیح |
| --- | --- |
| **نام (Name)** | عنوان کوتاه و توصیفی گروه. |
| **توضیح (Description)** | توضیح جامع هدف و نحوه عملکرد گروه. |
| **سطح دسترسی (Visibility)** | عمومی (Public) یا خصوصی (Private). |
| **سطح جغرافیایی (Geographic Level)** | محله، شهر، استان، کشور، قاره یا جهانی. |
| **دسته (Category)** | عمومی، حرفه‌ای، تخصصی، سنی یا جنسیتی. |
| **آواتار (Avatar)** | هویت بصری گروه (حداکثر ۲MB). |

### دعوت با نام، ایمیل یا تلفن

از پنل مدیریت اعضا، از **Add Member** برای جستجوی کاربر با نام، ایمیل یا شماره تلفن استفاده کنید. کاربران دعوت‌شده تا پذیرفتن در وضعیت **مهمان (Guest)** قرار می‌گیرند.

## تنظیمات و نظارت

- **قوانین (Rules)** — قوانین و مرامنامه گروه.
- **مدیریت اعضا** — ارتقا به بازرس (Inspector) یا مدیر (Manager).
- **حالت باز/بسته (Open / Closed)** — وقتی باز است، ناظران هم می‌توانند پیام بدهند.
- **بی‌صدا و بایگانی (Mute / Archive)**.
- **مدیریت گزارش‌ها** — مدیران و بازرسان گزارش‌های اعضا را دریافت می‌کنند.

## نقش‌های عضویت

| نقش | توضیح |
| --- | --- |
| **ناظر (Observer)** | فقط خواندن |
| **عضو فعال (Active Member)** | مشارکت کامل |
| **بازرس (Inspector)** | نظارت بر گزارش‌ها |
| **مدیر (Manager)** | کنترل اداری کامل |
| **مهمان (Guest)** | دسترسی موقت |

<Note>
  اعضای گروه‌های سطح محله به‌طور خودکار وضعیت Active Member دریافت می‌کنند. در سطح شهر و بالاتر، وضعیت Observer است.
</Note>

## اتصالات خودکار گروه

لازم نیست برای هر موقعیت و حرفه‌ای، گروه دستی بسازید. با تکمیل ثبت‌نام، سیستم شما را به گروه‌های مرتبط اختصاص می‌دهد.
